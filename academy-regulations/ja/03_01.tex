\chapter{学期}
\begin{enumerate}[label=第\arabic*条　]
  \item この章は、憲章の趣旨に基づき、学園の活動を円滑に行うため、活動期間の単位として学期に関し必要な事項を定めるものとする。
  \item 学園における学期は、次の各号に掲げる期間とし、半年ごとに繰り返し設定する。
      \begin{enumerate}[label=(\arabic*)　]
        \item ４月１日から９月３０日まで
        \item １０月１日から翌年３月３１日まで
      \end{enumerate}
    \begin{enumerate}[label=\arabic*　,start=2,leftmargin=*]
      \item 前項各号の学期における正規活動期間及び補講期間は、それぞれ次の各号に定めるとおりとする。
        \begin{enumerate}[label=(\arabic*)　]
          \item 前項第１号の学期　正規活動期間は４月１日から７月３１日まで、補講期間は８月１日から８月１５日まで
          \item 前項第２号の学期　正規活動期間は１０月１日から翌年１月３１日まで、補講期間は翌年２月１日から翌年２月１５日まで
        \end{enumerate}
    \end{enumerate}
  \item 次の各号に掲げる学期の募集期間は、それぞれ当該各号に定める期間とする。
      \begin{enumerate}[label=(\arabic*)　]
        \item 前条第１項第１号の学期　２月１５日から４月１５日まで
        \item 前条第１項第２号の学期　８月１５日から１０月１５日まで
      \end{enumerate}
    \begin{enumerate}[label=\arabic*　,start=2,leftmargin=*]
      \item 募集期間は、当該学期の正規活動期間の開始後も継続することができる。
    \end{enumerate}
  \item 学園における学期は、開校（本開講）時における最初の学期を「＃１期」とし、以後、第２条第１項各号の別を問わず、開始の順に１を加えて付番する。
    \begin{enumerate}[label=\arabic*　,start=2,leftmargin=*]
      \item 最初の学期の開始時期その他必要な事項は、教務主事が別に定める。
    \end{enumerate}
  \item 教務主事は、運営上やむを得ない事由があると認めるときは、第２条及び第３条に定める期間を変更することができる。
    \begin{enumerate}[label=\arabic*　,start=2,leftmargin=*]
      \item 前項により期間を変更したときは、教務主事は、速やかにこれを学生に公示しなければならない。
    \end{enumerate}
  \item この章の実施に関し必要な事項は、教務主事が別に定める。
\end{enumerate}
