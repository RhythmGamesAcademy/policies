\chapter{秩序の維持}

\begin{enumerate}[label=\thechapter.\arabic*　,leftmargin=*]

  \item \textbf{秩序の維持とは何か}

  秩序の維持は、学生が安心して探究活動を続けられる状態を保つことをいう。
  違反者を見つけて処分することが目的ではない。

  学園憲章第３条第２項は、互いの自由を尊重し健全な秩序を維持する義務を全構成員に課している。
  教務主事がこの義務を肩代わりするわけではなく、学生同士で解決できることに介入する必要はない。

  \item \textbf{認知したとき}

  問題を認知したときは、まず事実を確認する。
  通報や相談を受けた場合も、一方の説明だけで判断しない。

  確認の過程は記録に残す。
  後に処分を行うときも、行わないと判断したときも、何を確認してそう結論したかが必要になる。

  \item \textbf{介入するかどうか}

  介入は必要な最小限度にとどめる（学園規則第４章第５条）。

  声をかけて解決するなら、それ以上のことはしない。
  当事者間で解決したのであれば、教務主事が改めて処分を行う必要はない。

  介入するかどうか迷うときは、そのまま放置した場合に他の学生の活動が妨げられるかを考える。
  妨げられないのであれば、急いで動く理由はない。

  \item \textbf{処分の段階}

  処分は警告、活動停止、除名の順に段階的に行う（学園規則第７章第６条）。

  警告を受けた学生が同じ学期内に再び違反したときは活動停止、活動停止を受けた学生が期間中又は終了後に再び違反したときは除名を行うことができる。
  警告の効力が学期内に限られるのは、過去の違反を無期限に持ち越さないためである。

  段階を飛ばせるのは著しく重大な違反があるときに限る（学園規則第７章第７条）。
  何が著しく重大かは事案によるが、他の学生に回復しがたい不利益が生じている場合が典型である。

  \item \textbf{緊急の措置}

  学園の秩序又は学生の安全が現に害されているか、害されるおそれが急迫しているときは、処分の手続きを経ずに活動へのアクセスを一時的に制限できる（学園規則第７章第８条）。

  これは処分ではなく、被害の拡大を止めるための応急措置である。
  したがって次の三点を必ず守る。

  \begin{enumerate}[label=(\arabic*)　]
    \item 遅滞なく本人に理由を通知する。
    \item 措置は当該学期の末日までに効力を失う。放置して既成事実にしない。
    \item 措置とは別に、処分を行うかどうかを改めて判断する。
  \end{enumerate}

  緊急の措置を採ったときは、速やかに他の教務主事に共有する。

  \item \textbf{役職者の場合}

  役職者が問題を起こしたときも、学生としての処分は他の学生と同じ基準で判断する。
  役職を解くことで処分に代えない（学園規則第７章第３条第３項）。

  役職者としての適格を欠くときは解任を検討するが、これは処分とは別の手続きである。
  解任は学園長が教務主事の協議を経て行い、学園長自身が対象のときは教務主事の協議による（学園規則第７章第３条）。

  \item \textbf{不服申立てを受けたとき}

  処分、緊急の措置又は解任を受けた学生は、不服を申し立てることができる（学園規則第７章第９条）。

  申立てがあったときは、当該判断を行った者以外の役職者が審査に当たる。
  自分が行った判断についての申立てを、自分で審査しない。

  審査では、事実の認定が正しかったか、選んだ手段が必要最小限であったかを見る。
  結論を維持する場合も、その理由を申立人に伝える。

  \item \textbf{記録}

  処分及び緊急の措置は、内容、理由、時期を記録に残す。
  警告についても同様とする。

  警告の記録がなければ、同じ学期内の再違反を確認できず、段階的処分が機能しない。

\end{enumerate}
