\chapter{講師規則}
\begin{enumerate}[label=第\arabic*条　]
  \item この章は、音楽ゲーム学園学園憲章（以下「憲章」という。）の趣旨に基づき、講師の資格その他必要な事項を定めるものとする。
  \item この章において「講師」とは、学生のうち、所定の申請を経て学園長又は教務主事の認可を受けた者をいう。
  \item この章において「講義」とは、講師が学生に対して提供する学習活動をいう。
  \item 学生は、次の各号に掲げる事項に同意した上で所定の申請を行うことにより、講師となることができる。
      \begin{enumerate}[label=(\arabic*)　]
        \item 学園が、学内活動の目的に必要な範囲において、当該学生が作成する講義資料を無償で使用し、及び配信すること
        \item 学園が別に定める講師に関する指針を遵守すること
      \end{enumerate}
  \item 講師の活動は、無報酬とする。講師は、講義の実施その他の講師活動に対し、報酬その他の対価を受けないものとする。
  \item 講師は、担当する講義の内容、構成及び進め方について、自らの裁量により定めることができる。
  \item 講師は、誠実に講義活動を行うよう努めるものとする。
  \item 講師としての地位の喪失に関する事項は、第１章第６条及び第６章に定めるところによる。
  \item この章の実施に関し必要な事項は、学園長が別に定める。
\end{enumerate}
